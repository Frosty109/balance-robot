**Status:** Resolved / Unresolved / Workaround

**What happened:** What the problem was and when it appeared.

**Cause:** What was causing it (if known).

**Resolution:** What fixed it, or what was tried if unresolved.

If an issues file for today already exists, append to it rather than overwriting.
